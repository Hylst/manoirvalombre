# Manoir Valombre : La Lanterne Perdue

**Trouve la sortie avant minuit**

Joue en ligne sur : [https://games.hylst.fr/manoirvalombre/](https://games.hylst.fr/manoirvalombre/)

## Description
Une aventure point and click immersive d'Halloween. Explore les pièces ténébreuses du manoir avec ta lanterne de citrouille, inspecte les objets suspects et résous les énigmes pour fuir.

## Controles
| Contrôle | Action |
|---|---|
| Clic / Tap | Interagir avec le décor et l'inventaire |
| Glisser | Déplacer le faisceau de la lanterne |

## Developpement
```bash
# Installer les dependances
npm install

# Lancer le serveur local
npm run dev

# Compiler pour la production (build single-file)
npm run build
```
